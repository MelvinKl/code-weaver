**Summary.** Four requirement files changed against the run's baseline; every diff rewords or extends existing baseline content (each carries a baseline index hash — no file is new), so this is a **standing in-place delta, not the brownfield all-new shape** — the standing instructions govern. `setup-pi.feature` **adds five scenarios** (a declared extension-env provider whose values did not arrive fails the stage at its entry, before any pi call, with the relay-half log and the artefact log naming the relay loss; - [x] **Every stage job delivery-checks the declared harness providers at its entry, before any stage work.**
  1. *Goal and its requirements.* A shared stage-entry check (the shared plumbing is the documented home of the stages' shared machinery, and the stage entry already applies the recorded extension env at entry — the check gates that application) runs in every stage job, before any stage work or pi call of the stage: for each of the run's four harness providers — the model configuration, the additional packages, the MCP configuration, the extension's environment — the ones **declared** for the run (the extension env's declaration is the trigger's flag from step 1; the other providers' declarations and their recorded values are set up by the setup stage as state files in the run's state dir, the same state-dir artefact channel the extension-env values already ride) must have their recorded values **restored into the job** — both relay halves (the state files present in the restored state dir; the values carried in the job's env by the per-job Read trigger state relay). A provider that is **not** declared (flag absent or false, no state file expected) passes the check: the run is unchanged — no files, no flag, no spurious failure. A harness that would otherwise **fall back silently** (an element that would run absent when its provider is absent) is treated as the same class of loss: declared-but-lost fails the entry check instead of degrading quietly. Fulfils setup-pi.feature **"A declared extension-env provider whose values did not arrive fails the stage at its entry" (new)**, **"The delivery check applies to every declared harness provider" (new)** and **"A run whose extension-env provider is absent is unchanged by the delivery check" (new)**.
